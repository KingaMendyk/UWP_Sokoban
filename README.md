# UWP Sokoban

This repository contains a Sokoban game developed as a Universal Windows Platform (UWP) application.

## About the Project

Sokoban is a classic puzzle game where the player pushes boxes to designated storage locations within a warehouse maze. This project was created to demonstrate skills in building interactive UWP applications, with a focus on user experience and smooth gameplay.

## Features

- Classic Sokoban mechanics
- User-friendly graphical interface
- Multiple levels with increasing difficulty
- Keyboard controls for seamless movement

## Getting Started

### Prerequisites

- Windows 10 or later
- Visual Studio 2019 or later with UWP development tools

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/KingaMendyk/UWP_Sokoban.git
   ```
2. Open the solution file (`.sln`) in Visual Studio.
3. Build and run the project using the local machine.
